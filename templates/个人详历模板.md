# 个人详历填写模板（完整详历模板）

> 用途：复制本文件为项目根目录的 `个人详历.md` 后填写，或让 Agent 根据本人材料/问答创建草稿。经本人确认后，该文件是简历生成的唯一事实母本，并在生成阶段保持只读。
>
> 原则：只写真实、可回溯的信息；不确定就标记“待确认”；不要把目标写成成果，不要把团队成果全部归为个人成果。首次使用可改用 `个人详历快速模板.md`，不必一次填完本文件。
>
> 脱敏：公开仓库前删除电话、邮箱、地址、身份证明、保密客户名称及未公开业务数据。

## 0. 填写与维护说明

- 事实时态：区分“已完成 / 进行中 / 探索中 / 计划中”。
- 角色边界：准确使用“负责 / 参与 / 协助 / 独立搭建”等表述。
- 数字口径：保留统计周期、对象、单位和数据来源；无可靠数据时写定性事实。
- 证据编号：工作 `EXP-001`、项目 `PRJ-001`、能力 `CAP-001`、实践 `EXT-001`、材料 `EVD-001`，编号创建后尽量不变。
- 内容冲突：不要选择更有利的口径，记录冲突并标记“待本人确认”。
